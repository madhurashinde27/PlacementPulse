# PlacementPulse — Placement & Skill Gap Analytics

## 📌 Project Overview

PlacementPulse is a data analytics project designed to analyze student placement performance, skills, internship impact, job opportunities, and skill gaps.

The project combines SQL, Python, and Power BI to transform student and recruitment data into meaningful insights and an interactive dashboard.

## 🎯 Objectives

- Analyze overall student placement performance
- Compare placement rates across branches
- Understand the impact of internships, projects, and certifications
- Analyze student skill availability
- Identify skill gaps between students and job requirements
- Analyze companies and job opportunities
- Visualize placement insights using Power BI

## 🛠️ Technologies Used

- MySQL
- SQL
- Python
- Pandas
- Power BI
- Excel
- VS Code

💡 Key Insights
1. Overall placement rate is approximately 70%.
2. 14 out of 20 students are placed.
3. Internship experience shows a strong relationship with placement outcomes.
4. CSE and IT have higher placement outcomes than ENTC and MECH in the dataset.
5. Technical and communication skills can be analyzed to identify placement improvement areas.
